# Redes II — Web de test (v2)

## Uso
Abre `index.html` para elegir entre Parcial 1, Parcial 2 y Parcial 3. La web es estática y compatible con GitHub Pages.

- **Parcial 1:** todos los exámenes, entrenamientos y simulacro originales. Los archivos de preguntas originales no se han modificado.
- **Parcial 2:** apartados preparados para los temas 4–8; aún no hay preguntas.
- **Parcial 3:** apartado reservado.

## Archivos
- `index.html`: selección de parcial.
- `parcial.html`: lista los bancos correspondientes al parcial seleccionado.
- `test.html` y `script.js`: motor de test compartido.
- `preguntas.js`: registro de bancos.
- `data/parcial2.js`: bancos vacíos del Parcial 2.

## Probar sin tocar main
Crea la rama `feature/parciales-v2`, sube los archivos de este ZIP a esa rama y abre un pull request hacia `main` **sin fusionarlo**. Puedes probar localmente abriendo `index.html`, o publicar la rama en un GitHub Pages de prueba independiente. GitHub Pages del repositorio principal normalmente sigue publicando `main` hasta que se cambie su configuración.
